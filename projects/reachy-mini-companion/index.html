How it works

From microphone to speaker

The app runs on the robot as a Reachy Mini app, installed from a Hugging Face Space. The robot's microphone is streamed in small PCM frames to Gemini Live over a WebSocket, and replies are resampled to the speaker's rate and played back, driving a head wobble while the robot talks. The control page on port 7860 polls a small status endpoint about once a second for the live orb, transcript and audio counters.

The voice backend is an explicit setting (gemini by default, or openai), so a stray key for another provider can never switch it.

Debugging

Silent failures I tracked down

Getting a voice robot to actually speak meant finding several failures that gave no clear error.

  • Nothing connected at all. The app used a Gemini Live model name that doesn't exist, and the newest SDK defaulted to an API version that serves no Live sessions. Both gave the same opaque HTTP 404. I isolated it by connecting over a raw WebSocket, which worked, and comparing it with the SDK's URL.
  • The robot never heard anything. Mic audio was sent with a blob type that doesn't exist in the SDK, and the error was swallowed at debug level. I fixed the type, and an on-page counter now shows how many mic frames were sent.
  • It answered once, then went deaf. The SDK's receive() ends after every turn and the app didn't loop around it.
  • Crashes on an invalid key or empty audio. Both are now handled and reported on the page. A crash would also put the robot to sleep.
  • The head wouldn't lift. The daemon reported motors as enabled while the head was limp. Cycling torque off and on through the daemon API, then playing the wake-up move, fixes it. The app does this automatically, verifies the head height and retries.
  • Installing over flaky Wi-Fi. Heavy optional dependencies (mediapipe, jax, opencv-contrib) made the install time out. Moving them to an optional extra made it a light install.

FAQ

Questions

What is Reachy Mini Companion?

Reachy Mini Companion is a multilingual voice app Ajay Ummadi built for Reachy Mini. It uses the Gemini Live API, detects the language you speak and answers out loud in the same language while the robot moves. It is published as a Hugging Face Space and installs from the Reachy Mini dashboard.

Is it based on another project?

Yes. It started from the open-source Reachy Mini Conversation App by Pollen Robotics (Apache 2.0), which supported OpenAI only. Ajay added the Gemini Live backend, automatic language detection, a new settings page and the packaging. It is not affiliated with or endorsed by Pollen Robotics, Hugging Face or Google.

Do I need an API key?

Yes, a free Gemini API key. Paste it on the app's settings page and press Test & save.
